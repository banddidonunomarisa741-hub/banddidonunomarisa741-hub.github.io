# 中轴千年 · 北京中轴线的城址变迁与体素建筑群

网页打开先看**总图**：按真实经纬度叠合**金中都（1153）、元大都（1267）、明北京（1420/1553）、清北京（1644）与今天的二环、三环**，看清中轴线怎样从约东经 116.344°（金）移到 116.391°（元以后），明代又怎样北缩南扩。每次切换朝代都会先回到总图，标出下一座城的位置和迁移方向，再进入该朝代的体素建筑群。

- **总图**（真实比例，1 格约 25 米）：四座城的城墙、皇城、宫城、城门和中轴线，今天的水系、绿地、环路和经纬网；“播放变迁”按时间顺序演示城址迁移。
- **五个朝代场景**（示意比例）：金中都、元大都、明北京、清北京、今。场景四周刻度为真实经纬度，左上角显示画面中心坐标与今天对应的地名，右下角为真实比例小地图。
- **朝代建筑语法**：同一套构件按朝代换屋面坡度、出檐、斗拱、彩画、瓦色和屋脊装饰（金：绿琉璃、鸱尾、平缓深檐、过梁门道、廊院；元：白瓦绿脊、工字殿；明：深橙黄瓦、旋子彩画、券门；清：明黄瓦、陡峭举架、和玺彩画）。
- **四朝对照**：点击建筑，信息卡给出同一角色在各朝代的对应建筑（如宫城正门：应天门 → 崇天门 → 午门；外朝正殿：大安殿 → 大明殿 → 皇极殿 → 太和殿），点击即经总图飞过去。
- **近景细模**：靠近重点建筑时自动换成两倍精度细模，可见瓦垄、门钉、格扇、彩画金线、栏杆望柱。
- **自动补桥**：城门、宫门前有护城河或金水河的地方都修了桥，道路跨河处修平桥。
- **游览路线**（清代、今）：老师建议的两种走法——“一日游 · 精华线”（12～13 站）与“两个半天 · 详细线”（上午南段燕墩—天安门、下午北段端门—钟楼，共 31～34 站）。红色箭头沿虚线路径跳到下一站，镜头以固定机位飞过去（约 0.85 秒），右侧卡片给出实拍照片与“历史 / 用途 / 看点”，可自动播放，也可用 ← → 手动切换；不建模游客小人。其他朝代按轴线节点生成一条“沿中轴线”路线。
- **固定机位**：每站按实拍照片的常用角度取景；被树木、城墙挡住时自动抬高或偏转镜头。示意比例下院落被压缩，镜头常落在前一座门楼后面，这时把挡在前面的重点建筑临时改成半透明（如看太和门时的午门）。
- **清代细部**：太和殿月台东南角日晷、西南角嘉量，铜龟、铜鹤各一对，铜鼎（实有 18 座，示意 6 座）；太和门前一对铜狮，乾清门前一对鎏金铜狮；近景细模的屋角加出戗脊与走兽。
- **燕墩**：永定门外西侧的方形墩台与台顶乾隆御碑，“今”的南端从这里开始。
- 晨 / 昏 / 夜，中轴线高亮，变迁高亮，导览侧栏。

手机、电脑都可以打开。页面只有一个 `index.html`，不加载任何外部资源，双击即可本地运行，也可直接用 GitHub Pages 或 Netlify 发布。导览用的实拍照片放在 `photos/` 文件夹（文件名与建议机位见 [photos/README.md](photos/README.md)），缺照片时卡片显示建议机位，网页照常运行。

## 五个时期看什么

| 时期 | 画面时间 | 中轴线 | 看点 |
| --- | --- | --- | --- |
| 金 | 大定、明昌年间（约 1170—1190） | 丰宜门—通玄门，约东经 116.344° | 十三门夯土城；应天门出双阙（午门“凹”字形的前身）；大安殿廊院；龙津桥、千步廊；里坊；莲花池水系；天宁寺塔 |
| 元 | 约至元末年（1285 年前后） | 丽正门—中心台，约东经 116.391° | 夯土城墙十一门；工字殿、白瓦绿脊；太液池三宫鼎立；御苑毡帐；积水潭漕船；钟鼓楼在轴线以西 |
| 明 | 嘉靖三十二年（1553）修外城后 | 永定门—钟楼，约 7.8 公里 | 城墙包砖、“凸”字形城廓；左祖右社紧邻宫城；皇极殿九间带斜廊；承天门五间；大享殿三色瓦；万岁山无亭 |
| 清 | 乾隆年间（约 1750—1800） | 永定门—钟楼 | 太和殿十一间、两侧卡墙；天安门九间；景山五亭与轴线上的寿皇殿；祈年殿全青瓦；钟楼砖石；北海白塔 |
| 今 | 2024 年申遗成功时 | 永定门—钟楼（遗产区） | 城墙原址成二环路；天安门广场建筑群；永定门复建；前门步行街；15 处遗产构成要素 |

## 两种比例

北京中轴线全长约 7.8 公里，严格按比例缩放时单体建筑只有几个方块大。所以：

- **总图是真实比例**，回答“在哪里”：城址、中轴线、水系按经纬度绘制（约百米精度）。
- **朝代场景是示意比例**，回答“长什么样”：南北顺序、东西方位依据史料和官方地图，建筑放大、空旷路段压缩、次要街巷从略。四周经纬度刻度的间距不均匀，就是压缩所在。

## 开发

```bash
npm install
npm run build          # 重新生成仓库根目录的 index.html（GitHub Pages 直接使用）
npm run build:dist     # 输出到 dist/index.html，不覆盖根目录
```

- `src/geo.js`：经纬度投影、各朝代城址坐标、场景坐标与经纬度的换算、今地名
- `src/style.js`：朝代建筑语法（坡度、出檐、斗拱、彩画、瓦色重映射、屋脊装饰、门道形式）
- `src/kit.js`：体素构件（屋顶含盝顶、屋身、台基、城台、城墙、树木等）
- `src/arch.js`、`src/arch-jin.js`：具名建筑模型
- `src/eras/`：`map.js` 总图，`jin.js` 金中都，`yuan.js` 元大都，`mqm.js` 明清当代共用骨架，`common.js` 放置、水系、自动补桥
- `src/refine.js`：近景细模（两倍精度体素化 + 细部）
- `src/mesher.js`：剔除隐藏面 + 顶点环境光遮蔽的网格化，重点建筑单独成网格
- `src/mapview.js`：总图上的城墙、中轴线与迁移箭头
- `src/tour.js`、`src/tourdata.js`：游览路线、箭头跳跃、固定机位与遮挡处理、每站的历史 / 用途 / 看点文字
- `tools/photo-list.mjs`：重新生成 `photos/README.md` 照片清单
- `src/worker.js`：在后台线程生成场景与细模
- `src/engine.js`、`src/app.js`：渲染、阴影、时段、细模调度与界面交互

## 发布

- **GitHub Pages**：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
- **Netlify**：仓库已带 `netlify.toml`（构建命令 `npm run build:dist`，发布目录 `dist`）；或直接把含 `index.html` 和 `photos/` 的文件夹拖进 <https://app.netlify.com/drop>。
